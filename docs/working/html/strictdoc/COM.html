    1. System Startup Procedures
    UID: COM-001
    STATUS: Draft
    STATEMENT:

    The system shall provide automated startup procedures with health checks, service initialization, and status reporting to ensure proper system operation.
    RATIONALE:

    Automated startup procedures ensure consistent system initialization and reduce operator errors.
    2. System Shutdown Procedures
    UID: COM-002
    STATUS: Draft
    STATEMENT:

    The system shall provide graceful shutdown procedures with data preservation, service termination, and status reporting to ensure safe system shutdown.
    RATIONALE:

    Graceful shutdown procedures prevent data loss and system corruption.
